Number Strand · N.1c N.1c(ii) · Basic index laws
\[ a^p a^q=a^{p+q} \]
\[ \frac{a^p}{a^q} = a^{p-q} \]
\[ (a^p)^q=a^{pq} \]
\[ n^{1/2}=\sqrt n \]
Example \(2^3\times2^4=2^7=128\)
Number Strand · N.1c N.1c(iii) · Extended index laws
\[ a^0=1 \]
\[ a^{-r} = \frac{1}{a^r} \]
\[ a^{p/q} = \sqrt[q]{a^p} \]
\[ (ab)^r=a^rb^r \]
\[ \left(\frac ab\right)^r = \frac{a^r}{b^r} \]

Number Strand · N.5 N.5a · Concept & equality

Understand a set as a well-defined collection of elements and recognise that two sets are equal when they contain the same elements.

\[ A=\{1,2,3,4\} \]

\[ B=\{4,3,2,1\} \]

Same elements therefore \(A=B\).

Number Strand · N.5 N.5e · Set laws

Investigate whether intersection, union and difference are commutative and/or associative.

Commutative

\[ A\cup B=B\cup A \] \[ A\cap B=B\cap A \]

Associative

\[ (A\cup B)\cup C = A\cup(B\cup C) \] \[ (A\cap B)\cap C = A\cap(B\cap C) \]
