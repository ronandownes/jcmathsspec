What the ruler exploration shows

Distance is never negative.

The smallest possible distance is 0, when the two endpoints coincide.

Reversing the endpoints does not change the distance: |AB| = |BA|.

If C is an intermediate point on segment AB, then |AC| + |CB| = |AB|.
