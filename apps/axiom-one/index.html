Learning intention

By the end of this activity, you will be able to:

  • understand and state the Two-Point Axiom;
  • explain what distinct points are;
  • recognise coincident points — points in exactly the same position.

What is an axiom? An axiom is a mathematical statement that we accept as true without proof. It is a starting point for developing other mathematical results.

Why is the word distinct important?

Axiom 1: Through any two distinct points, there is exactly one straight line.

You are not proving the axiom. You are exploring it so that you understand exactly what it says.

Language point: Two points are distinct if they are in different positions. If two points lie in exactly the same position, they are called coincident points.
